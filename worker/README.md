# Сервер ИИ-сводки

Небольшой сервер на Cloudflare Workers. Работает в двух режимах:

- **Диагностика**: машина, описание, звук, коды ошибок и фото → поиск по форумам (Drive2, Drom, Reddit) и сервисным бюллетеням через встроенный веб-поиск Claude → сводка: срочность, вероятные причины, что проверить, цена ремонта, источники.
- **Проверка счёта** (`"mode": "estimate"`): текст или фото сметы автосервиса → сравнение каждой позиции с типичными ценами для машины и города.

Ключ Anthropic хранится только на сервере, в браузер пользователя он не попадает.

## Запуск (один раз, около 10 минут)

### 1. Ключ Anthropic
1. Зайдите на https://console.anthropic.com, зарегистрируйтесь.
2. **Billing**: пополните баланс (например, на $5) и поставьте месячный лимит расходов, чтобы не было сюрпризов.
3. **API Keys → Create Key**, скопируйте ключ (начинается с `sk-ant-`).

### 2. Cloudflare
1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатный тариф: 100 000 запросов в день).
2. **Workers & Pages → Create → Import a repository**, подключите GitHub и выберите `avto-reshenie`.
3. В настройках сборки укажите **Root directory: `worker`**, остальное оставьте как есть, нажмите **Deploy**.
4. Откройте созданный Worker → **Settings → Variables and Secrets → Add**: тип **Secret**, имя `ANTHROPIC_API_KEY`, значение — ключ из шага 1. Сохраните.
5. Скопируйте адрес Worker'а вида `https://avto-reshenie.<ваше-имя>.workers.dev`.

### 3. Подключить к приложению
Вставьте адрес в приложении: **Настройки → Адрес сервера ИИ-сводки**. Чтобы адрес работал у всех пользователей сразу, впишите его в `DEFAULT_AI_URL` в `index.html`.

## Локальная разработка
```
cd worker
npm install
echo "ANTHROPIC_API_KEY=sk-ant-..." > .dev.vars
npm run dev      # http://localhost:8787
npm run check    # проверка типов
```

## Настройки
- `ALLOWED_ORIGINS` в `wrangler.toml`: сайты, с которых разрешены запросы (сейчас `https://serg1306.github.io` и localhost).
- Модель: `claude-opus-5-5`, до 5 веб-поисков на одну сводку.
