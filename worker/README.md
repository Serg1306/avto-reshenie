# Сервер ИИ-сводки

Небольшой сервер на Cloudflare Workers. Работает в двух режимах:

- **Диагностика**: машина, описание, звук, коды ошибок и фото → поиск по форумам (Drive2, Drom, Reddit) и сервисным бюллетеням через встроенный веб-поиск Claude → сводка: срочность, вероятные причины, что проверить, цена ремонта, источники.
- **Проверка счёта** (`"mode": "estimate"`): текст или фото сметы автосервиса → сравнение каждой позиции с типичными ценами для машины и города.

Ключ Anthropic хранится только на сервере, в браузер пользователя он не попадает.

## Запуск (один раз, около 10 минут)

### 1. Ключ Anthropic
1. Зайдите на https://console.anthropic.com, зарегистрируйтесь.
2. **Billing**: пополните баланс (например, на $5) и поставьте месячный лимит расходов, чтобы не было сюрпризов.
3. **API Keys → Create Key**, скопируйте ключ (начинается с `sk-ant-`).

### 2. Cloudflare
1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатный тариф: 100 000 запросов в день).
2. **Workers & Pages → Create → Import a repository**, подключите GitHub и выберите `avto-reshenie`.
3. В настройках сборки укажите **Root directory: `worker`**, остальное оставьте как есть, нажмите **Deploy**.
4. Откройте созданный Worker → **Settings → Variables and Secrets → Add**: тип **Secret**, имя `ANTHROPIC_API_KEY`, значение — ключ из шага 1. Сохраните.
5. Скопируйте адрес Worker'а вида `https://avto-reshenie.<ваше-имя>.workers.dev`.

### 3. Подключить к приложению
Вставьте адрес в приложении: **Настройки → Адрес сервера ИИ-сводки**. Чтобы адрес работал у всех пользователей сразу, впишите его в `DEFAULT_AI_URL` в `index.html`.

## Подписка и оплата через Т-Банк

Бесплатно каждое устройство получает 3 ИИ-попытки за всё время, дальше нужна годовая подписка (`PRICE_RUB`, по умолчанию 300 ₽, в неё входит `PAID_PER_YEAR` ИИ-запросов). Подписка привязана к email покупателя: на другом устройстве её можно подключить кнопкой «Я уже оплачивал».

Чтобы включить оплату (после регистрации ООО):
1. Подключите интернет-эквайринг в Т-Бизнесе и онлайн-кассу для чеков (54-ФЗ), например Т-Чеки.
2. В личном кабинете эквайринга возьмите **TerminalKey** и **пароль терминала**.
3. В `wrangler.toml` впишите `TBANK_TERMINAL_KEY` и систему налогообложения ООО в `TBANK_TAXATION` (`osn`, `usn_income`, `usn_income_outcome` и т. д.). Пароль добавьте в Cloudflare как секрет `TBANK_PASSWORD`.
4. Уведомления о платежах сервер принимает по адресу `https://<ваш-сервер>.workers.dev/pay/notify`, он передаётся банку автоматически при создании платежа.
5. Сначала проверьте на тестовом терминале (у тестового TerminalKey окончание `DEMO`), потом переключите на боевой.

Адреса сервера: `POST /` — ИИ-сводка и проверка счёта, `GET /status` — остаток попыток и подписка, `POST /pay/init` — создать платёж, `POST /pay/notify` — уведомления банка, `POST /pay/restore` — подключить подписку по email.

## Локальная разработка
```
cd worker
npm install
echo "ANTHROPIC_API_KEY=sk-ant-..." > .dev.vars
npm run dev      # http://localhost:8787
npm run check    # проверка типов
```

## Настройки
- Лимиты (в `wrangler.toml`, раздел `[vars]`): `FREE_PER_DEVICE` — бесплатных ИИ-попыток с одного устройства за всё время (3), `LIMIT_PER_IP` — запросов в день с одного IP (15), `LIMIT_TOTAL` — запросов в день на весь сервис (100, примерно $15–25). День считается по московскому времени. Счётчики хранятся в Durable Object `Limiter`, Cloudflare создаёт его сам при деплое. Устройство определяется по случайному id в браузере: если очистить данные сайта, попытки начнутся заново, но дневной лимит по IP остаётся.
- `ALLOWED_ORIGINS` в `wrangler.toml`: сайты, с которых разрешены запросы (сейчас `https://serg1306.github.io` и localhost).
- Модель: `claude-opus-5-5`, до 5 веб-поисков на одну сводку.
