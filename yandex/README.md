# Серверы «АвтоРешения» в Яндекс Облаке

Российский вариант серверной части. Работает из России без ограничений, оплачивается российской картой или со счёта ООО, данные хранятся в России.

| Папка | Что делает | Что использует |
|---|---|---|
| `plate/` | Поиск машины по госномеру | api-cloud.ru (около 4 ₽ за проверку) |
| `ai/` | ИИ-сводка по проблеме и проверка счёта автосервиса | YandexGPT, Яндекс Поиск, распознавание текста на фото, Object Storage |

Обе функции написаны на Node.js 22 и не требуют сторонних библиотек: код вставляется прямо в редактор консоли.

## 0. Общая подготовка (один раз)
1. Откройте https://console.yandex.cloud и войдите через Яндекс ID.
2. Создайте **платёжный аккаунт**: привяжите карту (физлицо) или реквизиты ООО. Новым аккаунтам Яндекс обычно даёт стартовый грант.
3. Откройте каталог `default` и скопируйте его **ID** (строка вида `b1g…`). Он понадобится как `FOLDER_ID`.

## 1. Поиск по госномеру (`plate/`)
1. Зарегистрируйтесь на https://api-cloud.ru, пополните баланс, например на 300–500 ₽, и скопируйте ключ (токен, 32 символа).
2. В консоли откройте **Cloud Functions → Создать функцию**, имя `avto-plate`.
3. Среда выполнения: **Node.js 22**, способ: **Редактор кода**. Создайте файл `index.js` и вставьте в него содержимое `plate/index.js`.
4. Точка входа `index.handler`, таймаут **120** секунд, память 128 МБ.
5. В **Переменных окружения** добавьте `API_CLOUD_TOKEN` со значением ключа.
6. Нажмите **Сохранить изменения**. На вкладке **Обзор** включите **Публичная функция**.
7. Скопируйте **Ссылку для вызова** и впишите её в `PLATE_URL` в `index.html`.

## 2. ИИ-сводка на YandexGPT (`ai/`)
1. **Бакет для счётчиков бесплатных попыток.** Откройте **Object Storage → Создать бакет**. Имя, например, `avto-schetchiki` (должно быть уникальным во всём Облаке), доступ: **Ограниченный**. Создайте.
2. **Сервисный аккаунт.** Откройте **Identity and Access Management → Сервисные аккаунты → Создать**, имя `avto-ai`. Добавьте роли:
   - `ai.languageModels.user` — YandexGPT;
   - `search-api.webSearch.user` — Яндекс Поиск;
   - `ai.vision.user` — распознавание текста на фото;
   - `storage.editor` — счётчики в бакете.
3. **Функция.** Откройте **Cloud Functions → Создать функцию**, имя `avto-ai`. Среда **Node.js 22**, **Редактор кода**, файл `index.js` с содержимым `ai/index.js`.
4. Точка входа `index.handler`, таймаут **120** секунд, память **256 МБ**.
5. **Сервисный аккаунт** функции: выберите `avto-ai`. Через него функция получает доступ ко всем сервисам, ключи хранить не нужно.
6. **Переменные окружения:**
   - `FOLDER_ID` — ID каталога из шага 0;
   - `BUCKET` — имя бакета из пункта 1.
7. Нажмите **Сохранить изменения**, включите **Публичная функция** и скопируйте **Ссылку для вызова**.
8. Впишите ссылку в `DEFAULT_AI_URL` в `index.html` и поставьте `AI_ENABLED = true`, чтобы показать ИИ-функции на сайте.

### Как работает сводка
1. Функция ищет в Яндексе по машине и проблеме (в том числе на drive2.ru) и берёт до 10 найденных страниц с отрывками текста.
2. Если приложены фото (JPEG или PNG), с них распознаётся текст: коды ошибок, строки сметы. Сам YandexGPT картинки не «видит», поэтому фото приборной панели без надписей мало что дадут.
3. YandexGPT пишет сводку в том же виде, что и раньше: срочность, причины, что проверить, цены в рублях, источники. В источники попадают только реально найденные страницы.

### Настройки (переменные окружения `avto-ai`)
- `YANDEX_MODEL` — модель, по умолчанию `yandexgpt-5.1` (YandexGPT Pro 5.1). Можно попробовать `aliceai-llm`.
- `FREE_PER_DEVICE` (3) — бесплатных сводок на устройство за всё время; `LIMIT_PER_IP` (15) и `LIMIT_TOTAL` (100) — сводок в день с одного IP и всего на сервис.
- `ALLOWED_ORIGINS` — сайты, с которых разрешены запросы, по умолчанию `https://serg1306.github.io`.

### Чего пока нет
Оплата подписки через Т-Банк пока осталась только в варианте для Cloudflare (`worker/`). Её перенос в Яндекс Облако — следующий шаг, после регистрации ООО и подключения эквайринга.

## Что не показывается
Данные владельцев машин (ФИО, телефон, адрес) нигде не запрашиваются и не показываются: это персональные данные, их защищает закон 152-ФЗ.
