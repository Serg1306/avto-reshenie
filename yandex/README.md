# Сервер поиска по госномеру в Яндекс Облаке

Российский вариант сервера: функция в Яндекс Облаке (Cloud Functions). Работает из России без ограничений, оплачивается российской картой, данные остаются в России. Первый миллион вызовов в месяц бесплатный, так что платить придётся только за проверки на api-cloud.ru (около 4 ₽ за номер).

Код функции: `plate/index.js`, без сторонних библиотек.

## Запуск (около 15 минут)

### 1. Ключ api-cloud.ru
1. Зарегистрируйтесь на https://api-cloud.ru.
2. Пополните баланс, например на 300–500 ₽.
3. В личном кабинете скопируйте ключ (токен, 32 символа).

### 2. Яндекс Облако
1. Откройте https://console.yandex.cloud и войдите через Яндекс ID.
2. Создайте платёжный аккаунт: привяжите карту (физлицо) или реквизиты ООО. Деньги не спишутся, пока не превышен бесплатный объём.
3. В каталоге `default` нажмите **Создать ресурс → Функция** (или выберите сервис **Cloud Functions → Создать функцию**). Имя: `avto-plate`.
4. Среда выполнения: **Node.js 22**. Способ: **Редактор кода**. Создайте файл `index.js`, вставьте в него всё содержимое файла `plate/index.js`.
5. Точка входа: `index.handler`. Таймаут: **120** секунд (база ГИБДД иногда отвечает медленно). Память: 128 МБ.
6. **Переменные окружения**: добавьте `API_CLOUD_TOKEN` со значением ключа из шага 1.
7. Нажмите **Сохранить изменения**, дождитесь, пока версия создастся.
8. На странице функции в разделе **Обзор** включите **Публичная функция**.
9. Скопируйте **Ссылку для вызова** вида `https://functions.yandexcloud.net/d4e…`.

### 3. Подключить к сайту
Впишите ссылку в `PLATE_URL` в `index.html` (или пришлите её разработчику).

## Настройки (переменные окружения функции)
- `ALLOWED_ORIGINS` — с каких сайтов разрешены запросы, по умолчанию `https://serg1306.github.io`. Если сайт переедет на свой домен, впишите его через запятую.
- `PLATE_PER_DEVICE` (5), `PLATE_PER_IP` (10), `PLATE_TOTAL` (200) — лимиты проверок в день. Счётчики хранятся в памяти функции и сбрасываются при её перезапуске, поэтому главный потолок расходов — баланс на api-cloud.ru. Не кладите туда сразу большую сумму.

## Что не показывается
Данные владельца (ФИО, телефон, адрес) функция не запрашивает и не отдаёт: это персональные данные, их защищает закон 152-ФЗ.
