# АвтоРешение

Веб-приложение для автовладельцев: введите марку, модель и год (или VIN) и опишите проблему, приложение найдёт видео с решениями на YouTube и сделает краткую сводку.

- Расшифровка VIN: NHTSA vPIC (бесплатно, без ключа).
- Поиск видео: YouTube Data API v3 (ключ пользователя хранится только в его браузере).
- Устанавливается на телефон как PWA.

Запуск локально: `python3 -m http.server` в этой папке, затем откройте http://localhost:8000.
