Ключ YouTube API
Ключ хранится только в этом браузере. Бесплатно: 10 000 единиц в день, это около 90 поисков. Получить ключ: Google Cloud Console → APIs & Services → включить «YouTube Data API v3» → Credentials → Create API key. Без ключа приложение покажет готовые ссылки на поиск в YouTube.
